=== Urban Pass ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 0.2.0
License: MIT

Classes in Berlin you can book with both Urban Sports Club and Wellpass.

== Usage ==

* After activation the app replaces the front page. Turn that off under Settings → Reading.
* The app is always available at /urban-pass/ (if that page 404s, open Settings → Permalinks and click Save once).
* Embed it in any page with the shortcode [urban_pass].

The data in data/ is refreshed daily by a GitHub Action and deployed from the repository.
Not affiliated with Urban Sports Club or EGYM Wellpass.
